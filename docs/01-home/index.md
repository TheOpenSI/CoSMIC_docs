Cognitive System of Machine Intelligent Computing (CoSMIC) is an open-source AI orchestration platform developed by the Open Source Institute (OpenSI) at the University of Canberra. Rather than relying on a single AI model, CoSMIC dynamically coordinates specialised AI services, knowledge systems and reasoning engines to deliver more accurate, explainable and scalable outcomes.

CoSMIC provides a modular architecture that combines:

- AI service orchestration
- Retrieval-Augmented Generation (RAG)
- Knowledge management
- Multi-model support
- Sustainable AI observability
- Open-source extensibility
- Local and cloud deployment options

Whether deployed in research, education, government or enterprise environments, CoSMIC enables organisations to build sovereign AI systems while maintaining transparency, reproducibility and control over their data.

## Key Features

### AI Orchestration

CoSMIC coordinates specialised AI services rather than treating all requests identically. Requests are analysed and delegated to the most appropriate capability available within the platform.

### Retrieval-Augmented Generation

CoSMIC combines large language models with organisational knowledge, allowing responses to be grounded in uploaded documents and shared knowledge repositories.

### Multi-Model Architecture

Models can be hosted locally or accessed through external providers.

Supported deployment options include:

- Hugging Face models
- Ollama models
- OpenAI models

The routing model and response generation model can be configured independently.

### Knowledge Management

Knowledge can be maintained at multiple levels:

- Conversation scope
- User scope
- Shared organisational scope

This enables both personal and organisational memory systems.

### Sustainable AI

CoSMIC incorporates observability mechanisms capable of tracking resource utilisation associated with AI workloads, supporting sustainable and transparent AI operations. This tracks computing resource use — power, energy, and similar metrics — and is separate from usage statistics (queries per user, token counts), which are not currently active.

### Open Source

CoSMIC is developed as an open-source platform, enabling organisations to deploy, extend and audit the system according to their requirements.
