## 9. Next Steps

- Concepts: learn how orchestration, service discovery, models, context and RAG fit together.
- User guide: explore chat, document upload, knowledge scopes and model administration.
- Architecture: understand the responsibilities and interfaces of CoSMIC Core, CoSMIC UI and CoSMIC DB.
- API reference: integrate clients with the published backend endpoints.
- Development: add services, run tests and contribute changes.
- Deployment: harden configuration, secrets, persistence, networking and observability for organisational use.

## 10. Documentation Maintenance Rule

The website should treat branch READMEs, example environment files, compose definitions and API schemas as the source of truth. Avoid copying volatile implementation values into narrative pages. Where a value must be documented, name the target branch or release and link to the corresponding source file.
